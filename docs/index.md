# Jeninnet.Assertions Documentation

A fluent, framework-agnostic assertion library for .NET, built around the moment a check fails and someone has to read the message.

The book exists in two parallel editions, each written in its own language. They share the argument, not the sentences.

- [English edition](en/00-index.md)
- [النسخة العربية](ar/00-index.md)

Alongside the book, two runnable resources live in the repository. The consumer template under `consumers/` exercises the library end to end through the published NuGet package, and the FrameworkZoo samples under `samples/` run one shared suite on six test runners.
